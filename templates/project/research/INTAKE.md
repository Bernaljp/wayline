# Intake

What the owner has, in their own words. `wayline intake` (or a session using the `wayline` skill)
rewrites this file; until then the headings are the questions. Hand over anything, in any form:
a paragraph, a plan, references as bare identifiers, data pointers, a repository, an earlier
manuscript or a referee report (those are documents, kept with `wayline document add`).

What the research sets out to answer is not kept here: each objective, and each goal (an
objective with a measure), is recorded with `wayline objective add` and listed in
`research/OBJECTIVES.md`.

## Intent

What question this project answers, and what would count as an answer.

## References

One line per paper or document worth absorbing: a DOI, an arXiv id, a URL, a title, or a PDF.

## Data

What data exists, where it lives, what is held out, and what may not leave the machine.

## Code

The repositories the work builds on, each pinned to a commit.

## Constraints

Hardware, deadlines, licences, methods that are off the table, and what must not change.

## Autonomy

`interactive`, `checkpoints`, or `autonomous`.

## Radius

`strict`, `moderate`, or `exploratory`.

## Budgets

GPU hours, wall clock, and the usage windows the run may spend.

## Decisions that stay human-only

Decisions that change an objective (a goal's measure among them) or the data, and any class the
owner adds.
