      reference list, or a folder as a .zip. With no conversation to sort them, code guesses cautiously: an
      identifier makes a file a reference, added to INTAKE.md; review markers make it a critique; anything
      else is a document kept and read only. Each document is converted and listed in DOCUMENTS.md.
