# Protocol

1. Read the rubric. It asks one question about the output; that question is the only one you
   answer.
2. Read the fields of the output below. Each is listed under the JSONPath the fixture showed you;
   a path that matched nothing is shown as absent, and an absent field supports nothing.
3. Decide `pass` when the fields meet the rubric and `fail` when they do not. When the rubric
   names what counts as support, hold the fields to exactly that.
4. Give the reason in one paragraph: the rubric's words you applied and the field that settled
   it. On a fail, name each thing that fell short.
5. Return the verdict through the structured output.
