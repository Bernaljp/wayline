# 19 — OPEN-7 Default autonomy and the irreversible list

Type: grilling
Status: resolved
Blocked by: None
Brief: OPEN-7, Sections 6.2, C7

## Question

Default autonomy `checkpoints` (default), and the irreversible list: delete or overwrite data, force-push, push to shared branches, exceed the compute or usage budget, spend money, change the goal or the data, change the harness globally.

Confirm, and decide two additions: (a) any network write beyond fetching sources (uploads, submissions, posts) is irreversible; (b) which decision classes are `human_only` by default at intake (default: anything changing the goal or the data).

## Answer

Resolved 2026-09-11 by the owner in a batch grilling round (all defaults confirmed unless stated).

Default autonomy `checkpoints`. Irreversible: delete or overwrite data, force-push, push to shared branches, exceed the compute or usage budget, spend money, change the goal or the data, change the harness globally, any network write beyond fetching sources. `human_only` by default: decisions that change the goal or the data.
