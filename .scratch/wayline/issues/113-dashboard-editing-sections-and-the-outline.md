# 113 - Dashboard: editing sections and the outline

**What to build:** The owner can steer from the laptop or phone without a terminal. The five sections and the outline each get an edit button in the Paper view. It opens a plain text editor on the rendered file, and its save does exactly what a file edit does. The edit is written to the file and taken in before the next render through the render stamp, as 88 and 104 built it:

- new text becomes the owner's passages;
- changed text becomes the owner's replacement;
- removed text becomes a withdrawal;
- outline moves, placements, and notes become `outline.json` entries.

If code re-rendered the file while the editor was open, the save shows both versions and the owner chooses. Nothing is overwritten silently. A reason in Methods' parameter table is edited in place, one row at a time. Reports, the account, and the paper's parts are not editable.
