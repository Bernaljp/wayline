# The wayline user guide

Wayline turns a research intent into a project that runs itself under a Claude Code subscription: code decides what
runs, when, and what counts as done; models decide only content. This guide is for the owner of a project and for
someone new to wayline. It describes the release in `CHANGELOG.md`'s `## Unreleased` section (v1.1.0), in the words of
the glossary, `CONTEXT.md`.

You talk with a project normally, in the dashboard's chat or in a Claude Code session in the project, and you never
type a `wayline` verb or a label: the session records what you say through the verbs, asks one line only when
something is unclear, and confirms first what costs money or cannot be undone. Each page says what you say and what you
see first, then lists the verbs the session runs underneath, for reference.

The three autonomies come up on every page:

- `interactive`: you are told each thing as it arises, and you answer each decision.
- `checkpoints` (the default): decision tickets reach you as they open; the rest waits for your next conversation or
  the run's end notice.
- `autonomous`: everything is asked during setup; after it the decider answers what is not human-only, and you get
  only the end notice (and a notice when the login expires).
